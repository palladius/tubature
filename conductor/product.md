# Product Overview: Tubature 🐉 🧙 🚀

**Tubature** is an engaging, colorful pipe-puzzle game designed for kids (ages 6–8) and puzzle enthusiasts alike.

Players rotate pipe tiles on a grid so that water flows seamlessly from a Source tile through **EVERY** single tile on the grid (spanning tree mechanics).

## Key Themes & Features
- **Creature Themes**:
  - Dragon 🐉
  - Wizard 🧙
  - Space 🚀
- **Progressive Difficulty**: Smooth progression from simple small grids to larger, intricate puzzles.
- **Victory Celebrations**: Satisfying, joyful victory celebrations and animations on solving each puzzle.
- **Kid-Friendly Accessibility**: Intuitive touch interactions, vibrant visuals, and zero frustrating barriers.
